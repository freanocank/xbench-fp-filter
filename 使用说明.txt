   Xbench FP Filter — 使用说明
============================================================

## 环境要求
- Windows 10/11
- 网络连接（首次运行需下载约 10MB Python 运行环境）

## 快速开始

1. 解压到任意目录
2. 双击 run.bat
3. 首次运行自动安装环境；完成后自动打开工具页面，请保留启动窗口
4. 在「参数设置」页输入 API Key、Base URL 和模型，点击「应用并测试连接」
5. 回到「误报筛查」页上传 Xbench .xls 或 .xlsx 报告，点击「开始筛查」
6. 查看判定、按误报或保留复核筛选，抽查后下载过滤后报告、分析总表或全部结果 ZIP

设置仅在当前会话有效；重启后恢复 config.py 中的默认配置。
旧版 .xls 会自动转换，处理结果统一导出为 .xlsx，原文件不变。
同名的 .xls 和 .xlsx 导出后会重名，请先修改其中一个文件名再同时上传。
请将新版解压到独立目录，确认正常后再替换旧版。原有 API 配置可手动复制到新版 config.py。

## 文件说明

├── run.bat         启动脚本（双击即可）
├── setup.bat       环境安装脚本（run.bat 会自动调用）
├── config_template.py  配置模板，参考抄到 config.py
├── requirements.txt    Python 依赖清单
└── README.md       开发者文档

## 常见问题

Q: .xls 提示 File contains no valid workbook part？
A: 请使用包含「内嵌主题识别修复」的新版包。部分标准 .xls 内带主题 ZIP 数据，
   旧版可能误判为 .xlsx；新版会先识别真正的工作簿格式，再读取报告。

Q: 上传 .xls 提示 application/vnd.ms-excel files are not allowed？
A: 旧版页面只接收 .xlsx。请使用本次包含 .xls 兼容修复的完整新版包。
   无需手动修改文件扩展名。新版 run.bat 会检查旧版 Excel 读取组件，缺失时自动安装。

Q: 缺少 DLL / 无法启动 Python？
A: 安装 Visual C++ Redistributable：
   https://aka.ms/vs/17/release/vc_redist.x64.exe

Q: 安装窗口中文乱码？
A: 使用本次更新的 run.bat 与 setup.bat。新版会在输出中文前启用 UTF-8，
   请勿用旧脚本覆盖新版；不要将 .bat 另存为带 BOM 的 UTF-8。

Q: pip 提示 Scripts 不在 PATH 中？
A: 新版安装时已抑制此路径提示；工具使用 python -m 调用，
   无需额外修改系统 PATH。

Q: API 连接失败？
A: 检查「参数设置」页的 API Base URL 是否正确，
   确认 API Key 没有过期。

Q: 想自己改模型列表？
A: 「参数设置」页有模型管理入口，支持新增/删除。
   数据保存在 data/custom_models.json。
